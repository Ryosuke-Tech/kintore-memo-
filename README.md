# 筋トレメモ

トレーニング・体重・食事を1か所で記録し、前回との比較やカロリー収支まで確認できるWebアプリです。HTML / CSS / JavaScript だけで作っており、サーバーやログインはありません。記録は、お使いのブラウザの中にだけ保存されます。

デモ: https://ryosuke-tech.github.io/kintore-memo-/ (GitHub Pagesで公開したあとのURLです)

## 主な機能
- **種目**: 登録・編集・削除・検索・部位での絞り込み(記録のある種目は削除不可)
- **トレーニング記録**: セット単位で記録。メイン / ウォームアップ / ドロップの区別、20字以内のメモ、推定1RM、前回の同じセットとの比較、日付別の表示、全期間検索
- **身体情報**: 身長・体重を日付と時刻つきで記録。基礎代謝(推定)を表示
- **カロリー**: 食品179件から、カロリーとPFCを自動計算。トレーニング時間から消費を計算し、収支を表示
- **グラフ**: 総ボリューム(種目・部位・日・週・月)、カロリー収支(日・週・月)
- **背景画像**: 自分の写真を選んで設定(初期は未設定。画像は端末の中にだけ保存され、このリポジトリには含まれません)
- **バックアップ**: 記録をファイルに書き出し・読み込み

## 使い方
- iPhoneでは、Safariで開き、共有ボタンから「ホーム画面に追加」して使うことをおすすめします。Safariで7日間触らないと、保存データが消える仕様があるためです。
- 記録は端末ごとに別です(同期はありません)。ときどき、ホームの「データのバックアップ」で書き出してください。

## 計算の方法と注意
- **推定1RM**: O'Conner式(重量×(1+0.025×rep))。kgのメインセットで、10rep以下のときだけ表示します。
- **基礎代謝**: Mifflin-St Jeor式(年齢・性別・身長・体重。体脂肪率や筋肉量は反映されません)。
- **消費カロリー**: (METs−1)×体重×時間。METsは Compendium of Physical Activities(2011年版)の値です。
- **収支**: 摂取 − 基礎代謝 − トレーニング消費。日常の活動分は含まれないため、実際よりプラス側に出やすくなります。
- 消費カロリーと収支は、**目安値**です。収支のグラフは、食事を記録した日だけを集計します。

## 食品データの出典
- 13件: 文部科学省「日本食品標準成分表(八訂)増補2023年」(食品成分データベース)で確認した値です。
- 166件: 「食べスコ」に載っている、日本食品標準成分表2020年版(八訂)準拠の値です。1件ずつ公式とは照合していないため、2023年の更新や2026年の正誤表で変わった食品は、公式の値と違う場合があります。
- PFCは、納豆、鶏むね肉(皮なし)、ばらベーコンのみ公式で確認しました。
